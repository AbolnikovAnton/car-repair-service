# Профессор — сайт-визитка автосервиса

Лендинг автосервиса по обслуживанию Honda: React + TypeScript + Vite, русский и иврит (RTL).

## Блоки

- Шапка с меню (ПК) и бургер-меню (мобильные), переключатель RU/HE
- Главный экран с анимированной иллюстрацией: Honda Jazz на ножничном подъёмнике
- Услуги — 12 карточек, плавно наезжают на главный экран при прокрутке
- Отзывы клиентов — карусель
- Контакты — телефон, адрес, карта и форма записи, отправляющая заявку в WhatsApp

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `dist/`).

## Где что менять

- Телефон, WhatsApp, карта — `src/config.ts`
- Тексты на обоих языках — `src/i18n/dict.ts`
- Иллюстрация главного экрана — `src/components/HeroIllustration.tsx`

Контакты, цифры и отзывы в проекте вымышленные — замените их перед публикацией.
